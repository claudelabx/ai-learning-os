تنظیمات

اتصال Supabase و Migration داده‌های محلی — فاز فنی ۴-ب طبق سند 011.

اتصال Supabase

Project URL و anon key را از داشبورد Supabase (Project Settings → API) کپی کنید. anon key پیش از ذخیره در همین مرورگر رمزنگاری می‌شود (سند 009) — با این‌حال چون این اپ کاملاً Client-side است، این رمزنگاری محرمانگی مطلق ایجاد نمی‌کند، فقط از نمایش ساده هنگام مرور مستقیم LocalStorage جلوگیری می‌کند.

اتصال AI Gateway

آدرس Serverless Function روی Vercel (طبق سند 008/128). کلید واقعی مدل‌های AI هرگز اینجا وارد نمی‌شود — فقط روی Vercel، در Environment Variables، ذخیره می‌شود. اگر روی همان دامنه‌ی Vercel این پروژه هاست شده، فقط /api/ai-gateway کافی است.
